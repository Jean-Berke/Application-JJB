# Git workflow

Ne jamais créer de commit, pousser sur GitHub, fusionner une branche ou ouvrir une pull request sans autorisation explicite de l'utilisateur, donnée dans le message en cours. Conserver les modifications localement par défaut et attendre une demande claire ("commit", "push", "fusionne", "ouvre une PR") avant d'exécuter l'action correspondante.
